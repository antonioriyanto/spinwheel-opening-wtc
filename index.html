PIN Akses Admin: 1234
  1. Buka Google Sheets baru di Google Drive toko, lalu klik menu Ekstensi > Apps Script.
  2. Ganti seluruh isi file dengan kode di bawah ini dan tekan Simpan.
  3. Pilih Terapkan (Deploy) > Deployment baru > Aplikasi Web.
  4. Atur akses ke Siapa saja (Anyone), terapkan, lalu tempelkan URL Web App ke kolom di atas.
